# Reusable Snippets

Snippets are small, context-specific building blocks. They are not complete solutions.

## Required use checks

- Confirm the execution context and function support.
- Supply validated inputs, configuration, authorization, consent, and logging.
- Define data contracts, primary keys, retention, and duplicate behavior before data mutation.
- Keep secrets and tenant IDs out of snippet code.
- Add a safe error path and production monitoring before release.

Use a complete example when the problem involves a workflow, persistence, integration, or customer-facing interaction.
